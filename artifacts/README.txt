This folder contains files generated during the electricity demand forecasting project.

Files:
- processed_data.csv: Cleaned and preprocessed dataset used for modeling.
- final_training_history.csv: Historical data used to train the final forecasting model.
- final_test_results.csv: Forecast evaluation results on the test dataset.
- final_model_comparison.csv: Comparison of model performance.
- models/final_sarima_model.pkl: Saved final Tuned SARIMA forecasting model.
- models/forecast_metadata.pkl: Metadata required to load and use the final model.

The final model and supporting files were generated through the forecasting workflow in forecast.ipynb.
